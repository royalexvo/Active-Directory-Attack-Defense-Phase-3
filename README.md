<h1>Password Spraying Attack & Defense</h1>

<h2>Description</h2>

This phase documents the simulation, investigation, and defense of a controlled password spraying attack against Active Directory domain accounts. The goal of this phase is to understand how password spraying targets multiple accounts, analyze the authentication activity generated by the attack, and implement defensive controls to reduce the risk of account compromise.

A Kali Linux virtual machine will be used as the attacker system to simulate password spraying against authorized test accounts. The resulting authentication activity will be investigated using Windows Security logs to identify suspicious patterns, evaluate account lockout behavior, and verify the effectiveness of implemented security controls.

<br />In this phase, the following topics will be covered:
- <b>Password spraying attack simulation</b>
- <b>Domain authentication activity</b>
- <b>Kali Linux attacker environment</b>
- <b>Windows security event analysis</b>
- <b>Failed authentication and account lockouts</b>
- <b>Password and account lockout policies</b>
- <b>Attack investigation</b>
- <b>Security monitoring and detection</b>
- <b>Defensive controls</b>
- <b>Remediation and hardening</b>
- <b>Post-remediation verification</b>

This phase provides hands-on experience with identifying, investigating, and defending against password spraying attacks within an Active Directory environment.
